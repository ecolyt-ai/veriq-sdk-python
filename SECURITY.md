# Security policy

Please do not report security issues in public GitHub issues.

Email **support@ecolyt.ai** with the subject line "Security: veriq-sdk" and include the
affected version, steps to reproduce, and any relevant request IDs. Never include a live
API key in a report; revoke any key you believe was exposed from the Veriq dashboard.

This repository contains only the client SDK. Issues with the Veriq API service itself can
be reported through the same address.
